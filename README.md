Iris Flower Classification using KNN with Streamlit
Project Overview

This project predicts the species of an iris flower using the K-Nearest Neighbors (KNN) machine learning algorithm. A simple and interactive Streamlit web application is used as the frontend, allowing users to input flower measurements and get instant predictions.

The model classifies iris flowers into three species:

Setosa
Versicolor
Virginica
Features
Train a KNN classifier on the Iris dataset
Predict iris flower species based on user input
Interactive Streamlit frontend
Clean and simple user interface
Real-time prediction display
Technologies Used
Python
Scikit-learn
Pandas
NumPy
Streamlit
